# إدارة المشيخة

إضافة مدخل «المشيخة» إلى لوحة الإدارة الحالية، يفتح محرر القسم مباشرة للأدمن والمشرف العام. يدعم تحرير العنوان والنص، وإضافة صور متعددة مع نص توضيحي ووصف بديل وإزالتها من المعرض. تبقى الصور الحالية افتراضية إلى أن يحفظ الأدمن معرضاً مخصصاً، ويظهر المحتوى المحفوظ بعد إعادة بناء الموقع الثابت.

التنفيذ يستخدم Next.js وReact وTypeScript وSupabase الموجودة، داخل `src/components/admin` و`src/lib`، مع ترحيل إضافي في `supabase/migrations`. تُحفظ الصور في `site-media` بقيود JPG/PNG/WebP و٥ ميجابايت. تبقى سياسات RLS الحالية؛ لا مفاتيح خادم في المتصفح، ولا حزم إضافية. تحديث الحالة يكون بنسخ جديدة مثل `setForm(current => ({ ...current, title }))`.

خطوات التحقق:
- اختبار فاشل ثم تنفيذ حفظ سجل مشيخة غير موجود وتحميل المعرض المحفوظ.
- اختبار دخول محرر المشيخة وتحرير النص ورفع صورة وحفظها، مع فشل الرفع والحفظ واشتراط الوصف البديل.
- تشغيل `npm run lint` و`npm run test` و`npm run test:a11y` و`npm run build:pages`، والتحقق بالمتصفح حيث تتاح بيئة مناسبة.

التفعيل على الموقع المباشر يتطلب تطبيق الترحيل على Supabase ثم نشر البناء. لا تُطبّق تغييرات خارجية ضمن التنفيذ المحلي دون تفويض النشر.

نتيجة التحقق:
- نجح `npm run lint` دون أخطاء أو تحذيرات؛ نجح ١٠٠ اختبار في ٣٤ ملفاً، ونجح `npm run test:a11y`.
- نجح البناء الثابت وفهرس Pagefind في نسخة تحقق مطابقة على القرص D باستخدام Node 24 المرفق، بعد تعذر البناء على C بسبب نفاد المساحة وتعطل عامل البناء على Node 25. استُخدمت إعدادات Supabase تجريبية دون مفتاح خادم؛ لم تُجلب بيانات الإنتاج.
- نجح اختبار Chromium معزول على البناء الثابت: دخول تجريبي، فتح المشيخة، تعديل نص متعدد الفقرات، رفع صورة خامسة، حفظ السجل المفقود والتحقق من إعادة تحميله. لم يظهر تجاوز أفقي عند عروض ٣٢٠ و٧٦٨ و١٠٢٤ و١٤٤٠ بكسل، ولم تُسجل أخطاء JavaScript. استُبدلت استجابات Supabase ببيانات اختبار ولم تُكتب بيانات خارجية.
- تمت مراجعة ترحيل `20260914000000_add_sheikhdom_gallery.sql` واختبارات pgTAP محلياً؛ تعذر تشغيل اختبارات قاعدة البيانات لعدم تشغيل Docker. الترحيل لم يُطبّق على Supabase.

تحديث النشر ٢٠٢٦-٠٩-١٥:
- نُقل التنفيذ إلى نسخة نظيفة من أحدث main مع الحفاظ على المشيخة في الصفحة الرئيسية وروابط عرض الأقسام وتوحيد العناوين الحالي.
- طُبّق ترحيل قاعدة البيانات على Supabase بنجاح. اجتاز التحقق المعاملي وجود العمود، والتحقق من الوصف البديل والروابط، ومنع الإدراج ورفع الملفات للمجهول، والسماح للأدمن بالتعديل ورفع الصور. أُلغيت جميع كتابات التحقق في نهاية المعاملة.
- تحذيرات الاعتماديات الموروثة تحتاج مراجعة منفصلة بحلول ٢٠٢٦-٠٩-٢٢. لا يوجد خادم Next دائم أو مُحسّن صور في التصدير الثابت، ولا يُسمح برفع SVG. لم تتغير الاعتماديات.- التحقق النهائي لنسخة النشر: نجح lint، و١٠٨ اختبارات في ٣٩ ملفاً، واختبارات إمكانية الوصول الثلاثة، وbuild:pages كاملاً، ومسار Chromium للتحرير والرفع والحفظ على أربعة عروض شاشة.
